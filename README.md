# Process-of-Data-Wrangling-Project

**Data wrangling** is the process of collecting, assessing, and cleaning data to ensure it is ready for analysis, visualization, or building predictive models.

Did you know that data professionals spend nearly 80% of their time wrangling data, leaving only 20% for exploration and modeling? This might make some wonder if the effort is truly worth it. Consider this analogy: before a skyscraper rises above ground, a strong and often time-consuming foundation must be laid. Although costly and labor-intensive, this foundation is essential for the building to stand tall and serve its purpose for many years.

In this analysis, I covered all three stages of data wrangling: gathering data, assessing data, and cleaning data. The work involved three datasets: an existing tweet archive, a TSV file containing tweet images extracted using Python’s requests library, and a dataset scraped directly from Twitter, which includes metrics like favorites and retweets of dog-related tweets.

To evaluate the data, I addressed two key assessment categories:

* **Data quality issues** Problems with the contents of the data, such as missing values, inaccuracies, inconsistencies, and duplicates.
* **Tidiness issues**  which concerns related to the structure and organization of the data.

Both programmatic and visual methods were employed to identify and resolve these quality and tidiness issues.
